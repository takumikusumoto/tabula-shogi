# 0001. 外部重み・棋譜を一切使用しない完全スクラッチ開発の採用

- **ステータス**: 承認済み (Accepted)
- **決定日**: 2026-09-06
- **文脈**: プロジェクト開始時における開発哲学の決定

## 課題と背景

既存のオープンソース将棋AI（やねうら王、Apery等）のコードや、プロ棋士の棋譜、公開NNUE重みファイルを活用すれば、短時間で強い将棋エンジンを構築することは容易です。
しかし、本プロジェクトの目的は「他人の成果を再パッケージすること」ではなく、「何もない白紙（Tabula Rasa）から自己生成・自己対局によって知性が創発するプロセスを探求すること」です。

## 決定事項

1. 外部の学習済みモデル・重みパラメータ・評価関数バイナリの持ち込みを完全に禁止する。
2. 既存将棋エンジンのソースコードのコピー・移植を行わず、Rust標準ライブラリのみで完全スクラッチ実装する。
3. すべての学習データおよび知性は、自分自身の自己対局・自己探索のみによって生成する。

## 結果と影響

- 既存AIの流用に比べて開発難易度は格段に高くなるが、完全に独自の知能を獲得できる。
- プロジェクトの純粋性と研究価値が最大化される。
