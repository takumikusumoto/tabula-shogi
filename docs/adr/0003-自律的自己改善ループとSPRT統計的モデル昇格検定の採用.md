# 0003. 自律的自己改善ループとSPRT統計的モデル昇格検定の採用

- **ステータス**: 承認済み (Accepted)
- **日付**: 2026-09-13
- **対象**: Phase 5 におけるアリーナ対戦検定・自律的モデル昇格ループの設計方針

## 課題と背景

TabulaShogi では Phase 4 において、ゼロ外部依存のスクラッチ NNUE バックプロパゲーション学習器（`train-nnue`）を完成させました。
しかし、新たに学習された候補モデルが「現行の最強モデルに対して本当に勝率が向上しているのか」を客観的かつ統計的に検証する仕組みがなければ、過学習や手番の偏りによって弱体化したモデルを誤って採用してしまう致命的なリスクが存在します。

さらに、数万〜数十万局面の棋譜を自己生成しながら実力を継続的に伸ばすためには、「自己対局 ➜ データ蓄積 ➜ NNUE学習 ➜ レーティング検定 ➜ モデル昇格」の全工程を人間が手動で監視・実行するのではなく、完全自律的に回転し続ける自己改善ループの構築が不可欠でした。

## 決定事項

1. **先後交代ペアマッチ（Fair Game Pairing）の採用**:
   - 将棋特有の先手有利バイアス（約52〜54%）を統計的に完全に相殺するため、同一のランダム序盤局面（デフォルト6手）から、手番（先手・後手）を入れ替えた2局（1ペア）を1セットとして並列対戦させます。
   - 引き分け判定（最大手数の到達）も厳密に管理します。

2. **Wald の逐次確率比検定（SPRT: Sequential Probability Ratio Test）のゼロ依存数理実装**:
   - Stockfish 等の最高峰チェスエンジンで標準となっている SPRT を、外部統計クレートを一切使わず Rust 標準ライブラリ（`std`）のみで完全スクラッチ実装しました。
   - パラメータ設計：
     - 帰無仮説 $H_0: \Delta \text{Elo} \le 0$（実力向上なし）
     - 対立仮説 $H_1: \Delta \text{Elo} \ge 35$（実力が明確に向上）
     - 許容第一種・第二種過誤率: $\alpha = 0.05, \beta = 0.05$
   - 対数尤度比（LLR）を各対局終了ごとに更新し、上限境界値 $\ln((1-\beta)/\alpha) \approx 2.94$ に到達した時点で即座に **Pass（新モデル採用）**、下限境界値 $\ln(\beta/(1-\alpha)) \approx -2.94$ に達した時点で **Fail（不採用）** と早期判定し、無駄な計算リソースを大幅に節約します。

3. **完全自律型自己改善パイプライン（`SelfImprovementLoop`）の構築**:
   - 以下の 4 工程を指定世代数（iterations）だけ自律的に繰り返すループを配備しました：
     1. **自己対局（Generate）**: 現行ベストモデルで自己対局を行い、CSA棋譜と学習データセット（TSV）を自動蓄積。
     2. **学習（Train）**: 累積データセットからスクラッチ NNUE 学習器により新世代候補重みを育成。
     3. **検定（Evaluate）**: 現行ベストモデルと新世代候補モデルによるアリーナ先後ペア対戦を実施し、SPRT および勝率を判定。
     4. **昇格（Promote）**: SPRT 合格または勝ち越し（勝率 > 50%）時に、新モデルを正式な `best_nnue.bin` として昇格保存。

4. **ゼロ外部依存（Zero External Dependencies / Tabula Rasa）の堅持**:
   - 統計計算、並列アリーナ実行、モデル重みシリアライズ、ループ制御のすべてを外部クレートなしで完結させました。

## 結果と影響

- 人間の手動操作や外部の将棋対戦ツール（nodchip/shogi-server等）を一切介することなく、PCのCPUリソースを投入するだけでエンジンが自律的に自己対局・学習・検定・世代交代を繰り返す完全自動進化エコシステムが完成しました。
- 早期打ち切り（SPRT）により、無駄な対局リソースを最小化し、最短時間で統計的確証を得ながらモデルを育成できるようになりました。
