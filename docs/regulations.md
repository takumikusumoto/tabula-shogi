# TabulaShogi 開発レギュレーション（公式規定）

## 1. 基本理念（Core Principle）

TabulaShogi は、外部依存を持たず、Rust言語によって完全なゼロ（スクラッチ）から開発される将棋エンジンです。  
エンジンの強さ、探索アルゴリズム、評価関数、およびニューラルネットワーク表現を含むすべての知性は、本リポジトリ内部の自己創発のみに由来しなければなりません。

## 2. 許可事項（Allowed）

- 自己対局（Self-Play）の自動生成および強化学習。
- 一般的なゲーム木探索・機械学習アルゴリズムの実装（Alpha-Beta法、Minimax、MCTS、df-pn詰将棋探索、NNUEアーキテクチャ等）。
- スクラッチコードによるドメイン知識の実装（手動評価関数 HCE、Piece-Square Tables、玉安全度等）。
- 一般的な標準ソフトウェアライブラリの利用（標準的なRustクレート等）。

## 3. 禁止事項（Strictly Prohibited）

完全スクラッチ開発の純粋性を担保するため、以下の外部アセットの持ち込みを固く禁止します：

- 他の将棋エンジンが学習したモデル・重みパラメータ・評価関数バイナリ。
- 公開定跡データセットおよび外部の定跡データベース。
- 公開棋譜（プロ棋士の棋譜、ネット対局棋譜等）。
- 詰将棋データセットおよび終盤データベース（エンドゲームテーブルベース）。
- 外部の将棋エンジンによる評価値・最善手・探索木の利用。
- 外部エンジンを教師（Teacher）とした蒸留・教師あり学習。
- 既存の将棋エンジンのソースコードのコピー、移植、または翻案。

## 4. 学習とデータ生成（Training & Data Generation）

- すべての学習用データは、TabulaShogi 自身の自己対局および自己探索のみによって生成されなければなりません。
- 初期のモデル重みは、ランダム初期化または独自の数理的初期化を使用します。

## 5. 実行時規律（Runtime Integrity）

対局中（USI対局やベンチマークマッチ等）において、エンジンは完全に自律して着手を決定しなければなりません：

- 外部API、LLM、検索エンジン、オンライン解析サービス等への問い合わせは一切禁止します。

## 6. 行動規範・判断基準（Guiding Rule）

開発・実装において判断に迷った場合は、常に以下を自問してください：

> **「この変更は、外部の将棋エンジンや外部データが獲得した強さを持ち込んでいないか？」**

もし答えが「はい」である場合、その実装は固く禁止されます。
